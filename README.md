# AI Agent Skills & Prompt Assets

个人在真实使用中沉淀的 AI Agent 技能 / 专家提示词 / 工作流集合，MIT 开源。

**特点**：不是整理出来的通用方法论——每一条规则背后基本都对应一次真实踩坑记录。内容与具体 AI 平台解耦，WorkBuddy、Claude Code、Cursor、GPT 都能用（各目录 README 有适配说明）。

## 各模块简介

### 1. ima-weekly-review — 知识库周复盘自动化

从 ima 知识库扫描上周笔记，生成周复盘报告，存档回知识库，并通过 PushPlus 推送微信精简版。

**解决的真问题**：第一版报告被反馈"水分太大、看不到真实痛点"。根因是 AI 用列表接口的摘要字段当素材——摘要已是加工过的一层抽象，再加工一次产出全是"正确的废话"。现在强制读原文、结论可追溯、写死反水分禁令。另有：本地+云端双校验防重复、补跑窗口衔接、对象存储上传签名实现、中文编码坑清单。

### 2. personal-knowledge-base — 个人知识库搭建与内化

核心信条：**你看过的世界不是你，你理解的世界才是你。**

四块内容：什么值得存（判断标准）/ 两套目录结构（通用成长版 / 研究生科研版）/ 内化方法（三阶段 + 30 分钟卡片 + 五步加工）/ **AI 协作防错 6 事故**（AI 没读图就编笔记、批量移动丢数据、摘要套摘要……每条对应一次真实事故，附自检清单）。

### 3. research-squad — 科研学术团

覆盖化学科研全流程的多角色专家团队：选题调研 → 实验方案 → 数据处理 → 论文投稿。主理人（顾全之）统筹调度，四个成员（文思远-文献 / 方得准-实验 / 数理通-数据 / 章成文-论文）分工产出。5 份独立的角色定义 md + 完整编排 SOP，含跨平台适配说明（WorkBuddy 原生 / Claude Code subagents / 任意聊天 AI）。

### 4. workflows — 科研人机协作六 SOP

01 文献速通（读三遍模型）/ 02 电化学数据处理管线 / 03 代码学习（逐条讲解教学法）/ 04 实验方案设计 / 05 论文与组会 / 06 远程服务器日常。每份含：步骤、产出、验收标准、常见坑。使用前把 `00-总览.md` 的路径占位换成你自己的目录约定。

### 5. case-studies — Prompt 工程案例

「重写周复盘自动化」完整复盘：9 条病根诊断表（哪条导致什么后果）、重写后的 prompt 骨架（可直接套用）、5 条跨场景通用启示。

## 安装

把对应目录复制到你的 AI 的 skills / agents 目录（具体见各模块 README）：

```bash
# WorkBuddy
cp -r skills/* ~/.workbuddy/skills/

# Claude Code
cp -r skills/* ~/.claude/skills/
cp -r research-squad/agents/*.md ~/.claude/agents/
```

需要配置占位符的模块（如知识库 ID、推送 token）在各自 SKILL.md 顶部有说明表。

## 关于隐私

所有内容发布前均做过脱敏：密钥、知识库 ID、文件夹 ID、个人标识全部替换为占位符或泛化表述。fork 后要提交自己的配置，记得改回去。**不要把真实 token 提交进公开仓库。**
