# 什么值得存，什么该扔

## 一句话标准

**与我的内核相关、经过我理解、能够指导我行动的信息，才存。**

三个条件缺一不可。"相关"但不理解 → 是书签；"理解"但不相关 → 是别人的知识；"理解且相关"但不指导行动 → 是谈资。

## 存什么

### 值得存的两类

1. **自己的习惯和计划**——日常作息、学习安排、目标跟踪。这类是"自我观察数据"，外部永远搜不到，是你最独特的资产。
2. **自己消化后的外部知识**——从书、课、他人经验里学到的，**用自己的话重述过**的内容。

### 具体一点

| 内容 | 存 / 不存 | 理由 |
|---|---|---|
| 读完一本书后写的 3 条能用的收获 | 存 | 消化过 + 可行动 |
| 这本书的章节摘要（复制的） | 不存 | 网上有，没经过你 |
| 一次失败实验的复盘 | 存 | 你的独有经验 |
| 刷到的方法论长图 | 不存 | 没嵌入生活就是噪音 |
| 亲手做了一道菜的过程记录 | 存 | 有体感，能复现 |
| 美食视频链接 | 不存 | 消遣 |
| 和 AI / 他人的一次关键对话总结 | 存 | 决策轨迹，日后可追溯 |
| 每天的情绪流水账 | 少存 | 除非在做自我观察，否则低信息密度 |

## 不存什么（明确清单）

- **未经消化的转载**——原文链接放浏览器书签，别进知识库
- **纯情绪宣泄**——除非在做心理状态追踪，否则回顾时全是噪音
- **"以后可能有用"的东西**——90% 永远不会被翻出来。真需要时重新搜，成本比维护低
- **能随时搜到的事实性知识**——API 用法、命令参数。这类留给搜索引擎

## 信息的组织形式（两个维度都要记）

每条笔记至少包含两块：

1. **来源**——书名 / 作者 / 文章链接 / 课程名。追溯和验证用，也是日后判断可信度的依据
2. **核心内容**——用自己的话重述，**不是复制粘贴**

少了来源，日后无法验证；少了自己的话，说明你没理解，这条笔记对你没有价值。

## 六条习惯的具体做法

| 习惯 | 具体做法 | 频率 |
|---|---|---|
| 即时记录 | 灵感/有价值的信息随手扔进「收集箱」，不做分类 | 随时 |
| 定期整理 | 清空收集箱，分类、标记、提炼 | 每周 30 分钟 |
| 用自己的话重述 | 每条笔记用大白话解释核心观点 | 每条 |
| 建立关联 | 新笔记主动链接到已有笔记，形成网络 | 每条 |
| 定期回顾 | 复盘，更新过时内容，删除冗余 | 每月 / 每季度 |
| 实践输出 | 把知识用到实际工作生活中，用输出检验 | 持续 |

## 常见坑

**坑一：收集狂热期。** 刚搭好库的前两周会疯狂往里塞东西，第三周就再也不打开。解法：给收集箱设上限，超过 20 条必须先整理才能继续存。

**坑二：追求完美分类。** 花三天设计分类体系，实际用起来发现一半的东西不知道放哪。解法：先粗粒度（3-5 个顶层分类），用两周，按实际出现的东西再细分。

**坑三：只存不看。** 没有回顾机制的知识库一定会腐化。解法：把"每月复盘"做成定时任务，不是靠自觉。
