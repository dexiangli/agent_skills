# 周复盘_YYYY-MM-DD_YYYY-MM-DD

> 反水分是第一优先级。
> 宁可写"本周无"，也不要为了填满模板而扩写。

## 报告 A：本周实况

### 实际做了什么
按主题归纳，标注来源笔记标题。

### 想通了什么
严格标准：笔记里出现"原来 / 我发现 / 想明白了 / 关键是"才算。
找不到就写"无明确认知突破记录"，不许凑数量。

### 进行中任务的实际进展
有进度数字写数字，没有写"未记录具体进展"。

### 卡点与未闭环（重点）
- 明确写出的困惑
- 反复出现在多篇笔记里的同一问题（标注出现次数与篇目）
- 开了头没写完 / 有问号没答案 / 待办没打勾的条目

## 报告 B：状态对比

五维度标 提升 / 持平 / 下滑 / **数据不足**：

| 维度 | 判断 | 证据 |
|---|---|---|
| 知识产出量 |  | 本周 X 条 vs 上周 Y 条 |
| 认知深度 |  | 具体哪几篇 |
| 行动闭环 |  |  |
| 任务推进 |  |  |
| 状态/精力 |  | 只在笔记有直接表述时才判断 |

**给不出证据一律写"数据不足，不判断"，禁止凭感觉贴标签。**
「状态/精力」禁止从行文语气脑补，只认原话（累了 / 没时间 / 焦虑等）。

## 建议
2-4 条，只针对报告 A 列出的具体卡点。
每条必须是"下周能直接做的一个动作"，不是"要加强 XX 意识"。

## 写作禁令

- 不写"这体现了你在 XX 方面的成长/思维升级"这类拔高句
- 不写笔记里没有的推论
- 不用"深度思考""认知跃迁""系统性提升"这类空词
- 有效笔记 ≤ 3 条时如实说"本周输入很少"，不拉长窗口凑数
