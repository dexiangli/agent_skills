# Workflows 总览

标准流程模板。一套「人机协作」的科研工作 SOP：AI 助手执行，人类研究者把关验收。可直接套用，也可按自己的目录结构替换路径约定。

## 约定（使用时替换成你的）

| 占位 | 建议 |
|---|---|
| 助手 | 你正在用的 AI（WorkBuddy / Claude / GPT 等） |
| 研究者 | 你自己（人，最终验收者） |
| `data/` | 原始数据目录 |
| `code/` | 脚本/代码目录 |
| `deliverables/` | 产出目录（图表/文档成品） |
| `knowledge/` | 编译后的知识目录 |

## 模板索引

| 编号 | 场景 | 适用期 |
|---|---|---|
| 01 | 文献速通（拿到文献快速搞懂） | 入门期主力 |
| 02 | 电化学数据处理（CV/DPV/阻抗） | 实验开始后高频 |
| 03 | 代码学习（AI 逐条讲，人动手） | 学编程期 |
| 04 | 实验方案设计 | 选题/组会前 |
| 05 | 论文 / 组会汇报 | 出数据后 |
| 06 | 远程服务器日常（Linux） | 有服务器后 |

## 通用规则

- 完成 = 产出落地 + 知识沉淀 + 过程留痕（不是对话结束就完事）
- 人的验收是终点，不是文件落地
- 关键判断（选方案、定参数、拍板方向）由人做，AI 只给依据不给决定
