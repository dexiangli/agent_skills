# 工作流 03：代码学习（AI 逐条讲解，人动手）

**触发**：想弄懂某段代码（自己项目的 / 复现论文的 / 开源的）
**主导**：AI 助手讲解　**人**：亲自敲关键命令

## 铁规矩：逐条讲解

- 每条命令/每段代码拆开讲：**术语全称展开 + 中文翻译 + 为什么这么做**
- 禁止甩一段代码让人自己看
- 不懂的行**立刻停下补背景**，不等整段讲完
- 例："`model.train()`——train 是 PyTorch 模型对象的方法，作用是切换到训练模式（影响 dropout/batch norm 的行为），为什么这里必须调用：不调用的话某些层在推理和训练时表现不同，结果会错。"

## 步骤

1. **跑起来**（助手）：实际运行，输出执行过程、中间结果、报错——讲代码必须配真实运行，不能干讲
2. **逐条讲解**（助手）：按上面铁规矩
3. **人动手**：关键命令由人亲自敲（学习目的是自己会操作），助手出步骤 + 讲解 + 排错
4. **沉淀**：带逐行注释的学习笔记 → 知识库

## 产出
- 带逐行注释的学习笔记
- 跑通的代码

## 验收
- 人能独立说出每行的作用
- 人能自己改一个参数并预测结果（预测错 → 回炉）

## 节奏控制
- 一次只讲一个模块，讲透再进下一个
- 人说完"继续"再往下，不主动灌
