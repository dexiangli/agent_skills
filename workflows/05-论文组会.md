# 工作流 05：论文 / 组会汇报

**触发**：有了数据要写论文 / 组会周报 / 文献汇报
**主导**：AI 助手　**人**：审内容（AI 改格式，人改内容）

## 步骤

1. **素材归拢**（助手）：数据 + 实验记录 + 相关文献，核对齐全
2. **画图**（助手）：脚本批量出图（可替代 Origin），样式统一：
   - 字体/线宽/配色全局一致，图注完整（含条件参数）
   - 一个图只讲一个结论
3. **写作**（助手）：
   - 论文：introduction（综述引路）→ 方法 → 结果 → 讨论
   - 汇报：组会 PPT / 周报（一页一个核心结果）
4. **人审改**：助手出初稿 → 人改内容 → 助手改格式
5. **沉淀**：论文稿、PPT 归档

## 产出
- 论文初稿 / 组会 PPT / 周报

## 验收
- 人能讲明白每个图的结论
- 投稿/汇报前：数据、引用、格式**三查**（助手出检查清单）

## 三查清单
- [ ] 数据：每个数字可追溯到原始记录，图表与数据一致
- [ ] 引用：格式统一、无编造引用（每条可查）
- [ ] 格式：目标期刊/组会模板要求逐项核对
