# 工作流 02：电化学数据处理管线

**触发**：拿到实验原始数据（CV / DPV / 阻抗 / UV-Vis 导出的 CSV/txt）
**主导**：AI 助手一条龙：取数 → 写脚本 → 出图解读　**人**：核对参数

## 步骤

1. **取数据**（助手）：
   - 从仪器电脑/服务器拉取原始文件 → 本机 `data/`
   - 命名规范：`<任务号>_<日期>_<样品>.csv`
2. **写解析脚本**（助手）：
   - 读文件、去表头、基线校正（多项式拟合等）、峰值提取、批量处理
   - 方案给人过目 → 写代码 → 跑通 → 脚本留 `code/`，产出放 `deliverables/<任务号>/`
3. **出图解读**（助手）：
   - 可视化（中国读者默认约定：**涨红跌绿**）
   - 解读结果、核对参数（基线窗口、阈值是否合理）
   - 结论写进实验记录 → `knowledge/`

## 产出
- 清洗后数据 + 处理脚本
- 图表
- 实验记录条目

## 验收
- 人确认脚本参数合理、图能直接进实验记录/组会
- 关键数值（如峰电位）与手工/Origin 核对一致

## 常见坑
- 基线校正窗口选错 → 峰位/峰高系统性偏移（用已知样品标定）
- 表头格式随仪器厂商变 → 写脚本前先人工看 10 行原始文件
- 批量处理前先单文件验证，跑通再上全量
