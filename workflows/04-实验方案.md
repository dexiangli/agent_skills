# 工作流 04：实验方案设计

**触发**：课题方向定了 / 组会要提方案 / 想验证某个想法
**主导**：AI 助手出方案与对比　**人**：拍板选方案

## 步骤

1. **摸底**（助手）：检索方向文献 + 组内已有工作，提取可复用的实验思路
2. **出方案**（助手）：2-3 套可选方案 + 对比表——
   - 每套：做什么（变量）、怎么测（方法）、材料/试剂、时间成本、预期结果、风险
3. **理论计算**（助手，可选）：能斯特方程反推浓度范围、灵敏度估算等
4. **人选方案**：助手只给对比和依据，**不做最终决定**
5. **沉淀**：选定方案 → 知识库

## 产出
- 方案对比表
- 选定实验方案文档（含操作定义：做什么、怎么做、多少量）

## 验收
- 人能向导师讲清"为什么这么设计"
- 每步都有明确的操作定义
