# 工作流 01：文献速通

**触发**：拿到一篇文献 / 导师发来方向文章 / 想快速了解某主题
**主导**：AI 助手　**人**：按「读三遍」模型消化后做判断

## 背景：文献读三遍模型

第一遍**只记不懂清单**（不求解）；第二遍**补背景**（概念逐条弄懂）；第三遍**批判**（方法/结论站不站得住）。读不懂是常态，不是失败。

## 步骤

1. **检索确认**（助手）：检索确认文献来源、期刊、影响因子、作者背景
2. **速通卡**（助手）：按「读三遍模型」产出背景速通卡——
   - 论文在解决什么问题（一句话）
   - 方法链条：怎么测的、测了什么（英文术语锚定 + 中文脚手架）
   - 人可能不懂的概念清单 → 逐条补背景（一条一个解释，不讲大课）
3. **归档**（助手）：
   - 速通卡 → 知识库文献目录
   - 精读笔记 → 个人笔记库（Obsidian 类）
4. **可选批量**（助手）：多篇文献时写脚本建元数据索引（标题/期刊/年份/DOI）

## 产出
- 背景速通卡
- 人读完后的：一读不懂清单 → 二读补背景 → 三读批判钩子

## 验收
- 人能用自己的话讲出"这篇做了什么、怎么做的"
- 不懂清单清零（或明确留到二读）

## 术语约定
- 中文交流，术语英文锚定（如 electrochemical impedance spectroscopy 电化学阻抗谱）
- 首次出现的缩写展开全称 + 中文
