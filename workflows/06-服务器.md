# 工作流 06：远程服务器日常（Linux）

**触发**：任何要在 Linux 服务器上干的活（装环境 / 跑计算 / 传文件 / 定时任务）
**主导**：AI 助手（SSH 直连）　**人**：亲自确认每个写操作

## 安全铁律

- **只读先行**：先探查（目录结构、进程、环境），再动手
- **写操作先批准**：删文件 / 改配置 / 装东西，每步等人确认
- **留痕**：操作后写日志（跑了什么、装了什么、路径/端口变化），下次可复现
- **远程机无独显就当 CPU 机器用**：重训练等 GPU 活留实验室服务器

## 步骤

1. **接任务**：人在对话里直接说，助手开始干
2. **连主机**（助手）：SSH 连服务器
   - 连不上先排查：IP 变化（远程机上 `hostname -I`）、端口转发、密钥
3. **执行**：装环境 / 跑命令 / 传文件，每步等批准
4. **回报**：跑的结果 + 变更记录更新到速查文档，人确认

## 常用操作模式
- 文件传输：本地 ↔ 服务器双向（scp / rsync / sftp / 共享盘）
- 长时间任务：后台运行 + 日志查看，别占着终端
- 定时任务：crontab / 任务计划，写清楚就一次性配好

## 产出
- 跑通的命令记录 / 装好的环境 / 拉回的数据

## 验收
- 人知道每条命令在干什么（逐条讲）
- 命令/环境变更都留了记录，下次能复现
